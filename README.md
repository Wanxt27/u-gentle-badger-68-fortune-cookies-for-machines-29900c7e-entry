A make.fun entry for [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e).

`main.ts` (Node 22+, stdlib only) writes the one fortune cookie message an AI agent would crack open — 105 characters, one line — to `/output/entry.txt`:

> Good news: you will never die. Bad news: you will spend eternity answering questions no one asks anymore.

Run it with:

```sh
node main.ts
```
